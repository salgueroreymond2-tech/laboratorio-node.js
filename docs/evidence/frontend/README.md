# Evidencias visuales del frontend

Capturas locales de la página pública de desarrollo; no representan autenticación, notas ni producción. La revisión se realizó contra una instancia local de SecureVault con datos de estado reales y sin información personal.

- `inicio-1440.png`: ventana de escritorio 1440 × 1200.
- `inicio-320.png`, `inicio-390.png`, `inicio-768.png`: emulación móvil Edge a 320, 390 y 768 px de ancho. Se comprobó que el ancho del documento coincide con el viewport en esas medidas.

Son capturas de la parte visible de la página; no prueban todos los estados ni sustituyen pruebas de accesibilidad.
